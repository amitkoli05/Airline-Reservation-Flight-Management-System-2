SKYPATH AIRLINE MANAGEMENT SYSTEM - V6

Frontend: airline_system.html
Java console backend classes: AirlineSystem.java, FlightManager.java, Flight.java, Passenger.java, Reservation.java

FEATURES
- Flight Management: add, view, search, update, remove, status tracking
- Passenger Management: register full passenger records, search by passenger ID
- Reservation Management: auto seat assignment, cancel, list, booking by passenger ID, print E-Ticket
- Reports: flights, passengers, bookings, revenue and status summaries
- Professional flight detail view: passenger manifest, business/economy seat map and passenger details
- Browser demo data persists in localStorage

Run frontend by opening airline_system.html in a browser.
Compile Java console project with:
  javac *.java
Run with:
  java airline.AirlineSystem
